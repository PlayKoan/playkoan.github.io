# KOAN

A rule-discovery puzzle. A hidden rule says YES or NO to every koan, a row of 1 to 6
digits, each 1 to 4. Test koans (1 point each), then name the rule in a small word
language. A wrong guess costs 3. Lower scores are better.

## Ways to play

- In a browser: open [the page](index.html). It needs JavaScript.
- In a terminal: download [koan.py](koan.py) and run `python3 koan.py new`. It needs
  Python 3.11 or newer and nothing else.
- The same game as a folder: [koan-game.zip](koan-game.zip). Unzip it, go into the
  folder with `cd koan`, and run `python3 game.py new`.
- For AI agents: [agents.txt](agents.txt) has kits to paste into a chat.
- Play by link, one address per move: https://playkoan.vercel.app/play
